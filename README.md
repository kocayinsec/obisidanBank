# obsidian-bank

A small bank of ready-to-use Obsidian setups. Every folder is a self-contained template with default content only, no personal data.

| Template | What it is |
| --- | --- |
| [`to-do-daily`](to-do-daily) | One-page daily habit dashboard: round check buttons for today, a weekly grid you can page through, and a totals card. Turkish UI. |

Each template has its own README with requirements and install steps.

License: [MIT](LICENSE).

**Türkçe:** Obsidian için hazır kurulumlar bankası. Her klasör bağımsız bir şablondur ve yalnızca varsayılan içerik taşır, kişisel veri yoktur. Şu an içinde günlük alışkanlık panosu (`to-do-daily`) var.
